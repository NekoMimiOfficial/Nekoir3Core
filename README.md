# Nekoir3 Core  
Install requirements and run the following  
- in a terminal run `python3 -m NekoMimi` then in the shell type `reg w nekoir3c API_URL` use your own API_URL and then type `exit`  
- run `python3 main.py`  
- profit  

The app may crash if the request fails... i did no error handling  
Discord RPC works... and it's cursed :3  

This app is used to stream music and set discord RPC, just that
